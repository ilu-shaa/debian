| Команда | Что делает                   | Пример              |
| ------- | ---------------------------- | ------------------- |
| `pwd`   | показать текущий каталог     | `pwd`               |
| `cd`    | перейти в каталог            | `cd lab0`           |
| `mkdir` | создать каталог              | `mkdir hall`        |
| `touch` | создать пустой файл          | `touch file.txt`    |
| `echo`  | вывести текст                | `echo "Привет"`     |
| `cat`   | вывести/объединить файлы     | `cat file.txt`      |
| `ls`    | показать содержимое каталога | `ls -lR`            |
| `chmod` | изменить права доступа       | `chmod 755 dir`     |
| `cp`    | скопировать                  | `cp file copy`      |
| `mv`    | переместить/переименовать    | `mv old new`        |
| `ln`    | создать жёсткую ссылку       | `ln file link`      |
| `ln -s` | создать символическую ссылку | `ln -s target link` |
| `rm`    | удалить файл/ссылку          | `rm file`           |
| `rm -r` | удалить каталог с содержимым | `rm -r dir`         |
| `rmdir` | удалить пустой каталог       | `rmdir dir`         |
| `head`  | первые строки                | `head -5 file`      |
| `tail`  | последние строки             | `tail -5 file`      |
| `grep`  | найти строки                 | `grep "Луи" file`   |
| `sort`  | сортировать строки           | `sort file`         |
| `wc`    | посчитать строки/слова       | `wc -l file`        |
| `less`  | просматривать длинный текст  | `less file`         |
